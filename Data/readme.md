# 📂 Data folder

The dataset is **not stored in this repository** because of its size.

## ⬇️ How to get it
1. Open the UCI page: https://archive.ics.uci.edu/dataset/502/online+retail+ii
2. Download **Online Retail II** and save the Excel file as `online_retail_II.xlsx`.
3. Place it in this folder, or upload it to Google Drive and set `DATA_PATH` in the notebook.

## 🧾 What the file contains
- Two sheets: **Year 2009-2010** and **Year 2010-2011**
- 1,067,371 rows and 8 columns, from 1 Dec 2009 to 9 Dec 2011
- Columns: Invoice, StockCode, Description, Quantity, InvoiceDate, Price, Customer ID, Country
